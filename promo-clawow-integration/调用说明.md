# SSO / API 调用说明

## API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/auth/sso` | SSO 登录（验证 JWT，自动创建用户） |
| GET | `/api/usage` | 所有用户用量统计 |
| GET | `/api/usage/:account` | 单用户用量统计 |

## POST /api/auth/sso

**请求**:
```json
{ "sso_token": "<JWT>" }
```

**成功响应** (200):
```json
{ "success": true, "user": { "id": 1, "account": "xxx", "name": "xxx", ... } }
```

**失败响应** (400/401):
```json
{ "error": "sso_token 无效或已过期" }
```

## GET /api/usage

返回所有用户的用量统计：
```json
[
  {
    "account": "xxx",
    "name": "xxx",
    "phone": "xxx",
    "company": "xxx",
    "loginCount": 3,
    "analysisCount": 5,
    "lastLogin": "2026-01-01T00:00:00.000Z",
    "createdAt": "2026-01-01T00:00:00.000Z"
  }
]
```
